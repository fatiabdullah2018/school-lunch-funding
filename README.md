# School Lunch Funding System

A transparent crowdfunding platform for students' meal programs built on the Stacks blockchain, enabling direct school distribution and community support for student nutrition needs.

## Project Overview

The School Lunch Funding System creates a decentralized platform where community members can contribute to student meal programs with complete transparency. The system ensures funds reach intended recipients through verified distribution channels while maintaining student privacy and dignity.

## Key Features

### Donation Pool Management
- Community-driven funding collection
- Transparent allocation and distribution tracking
- Real-time funding status and needs assessment
- Automated fund distribution based on verified needs

### Student Verification
- Privacy-preserving student eligibility verification
- Anonymous need assessment and qualification
- Secure identity management without personal exposure
- Dignity-preserving access to meal programs

### Meal Distribution Tracking
- Real-time tracking of meal distribution to students
- Transparent fund utilization and impact measurement
- School-verified distribution confirmation
- Community impact reporting and analytics

## Smart Contracts

### 1. Donation Pool Contract
Manages the collection and distribution of community donations:
- Donation collection from community members
- Fund allocation based on verified student needs
- Transparent tracking of donation utilization
- Automated distribution to verified school programs

### 2. Student Verification Contract
Handles privacy-preserving student eligibility verification:
- Anonymous student registration and verification
- Need-based qualification assessment
- Privacy protection while ensuring legitimate access
- Integration with school verification systems

### 3. Meal Distribution Contract
Tracks meal distribution to ensure proper fund utilization:
- Real-time meal distribution logging
- School-verified distribution confirmation
- Impact tracking and community reporting
- Fund accountability and transparency measures

## Technology Stack

- **Blockchain**: Stacks
- **Smart Contract Language**: Clarity
- **Development Framework**: Clarinet
- **Testing**: Clarinet testing framework

## Getting Started

### Prerequisites
- Clarinet CLI installed
- Stacks wallet
- Node.js and npm

### Installation
1. Clone this repository
2. Run `clarinet check` to verify contract syntax
3. Run `clarinet test` to execute test suite
4. Deploy to testnet using `clarinet deploy`

## Contract Architecture

The system consists of three interconnected contracts working together to provide a complete meal funding ecosystem:
